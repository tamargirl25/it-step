Id და class

1. შექმენით HTML გვერდი, სადაც იქნება სამი განსხვავებული div ელემენტი id და class ატრიბუტებით.

2. გამოიყენეთ CSS და მიანიჭეთ თითოეულ class-ს განსხვავებული ფერები და სტილები. Box Model

box Model

3. შექმენით box model-ის გამოყენებით კონტეინერი, რომელიც შეიცავს padding, margin და border-ს.

4. შეცვალეთ padding და margin მნიშვნელობები და ნახეთ, როგორ მოქმედებს ისინი ელემენტის განლაგებაზე. Float (Left/Right)

Float (left/right)

5. შექმენით ორი div ელემენტი, ერთი მარცხნივ და მეორე მარჯვნივ float: left; და float: right; გამოყენებით.

6. დაამატეთ სურათი და ტექსტი გვერდიგვერდ, სადაც სურათი იქნება მარცხნივ (float: left;).

7. შექმენით ნავიგაციის მენიუ, სადაც ელემენტები იქნება განლაგებული float: left; გამოყენებით.
